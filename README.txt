CareerCompass — Find Your Career

Run locally:
1. Extract CareerCompass.zip.
2. Open index.html in a modern browser.

To publish and get a public website link:
- Upload index.html to a static hosting service such as GitHub Pages, Netlify, or Vercel.
- This is a static website and needs no backend.

Note: salary figures are broad illustrative U.S. estimates and should be verified for the user's country and current year.
